Neural Networks Project - Breast Cancer Classification

Name: Marah Akram Abou Abdo

Field: Machine Learning / Deep Learning

---

Project Overview:
This project uses a Neural Network model to classify breast cancer tumors as malignant or benign using the Breast Cancer Wisconsin dataset.

---

Steps in the Project:
1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Train/Test Split
4. Model Building using TensorFlow/Keras
5. Model Training
6. Evaluation (Accuracy, Precision, Recall, F1-score)
7. Model Optimization using Dropout and Early Stopping
8. Saving the final trained model

---

Tools Used:
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas, NumPy
- Matplotlib, Seaborn

---

Result:
The final model achieved high accuracy in classifying tumors and showed improved performance after optimization.
